# Code Of Conduct

Useproof should be a focused, respectful place to build useful open-source
software.

## Expected

- Be direct and kind.
- Assume good intent while still being precise.
- Keep feedback about the work.
- Respect privacy and do not post secrets, cookies, customer data, or private
  browsing artifacts.

## Not Accepted

- Harassment, threats, or personal attacks
- Doxxing or publishing private information
- Repeated off-topic promotion
- Abuse of issue templates, discussions, or review threads

## Reporting

Report conduct issues privately through the repository maintainer contact path
or GitHub moderation tools.

Maintainers may edit, hide, lock, or remove content that makes the project less
safe or less useful for contributors.
