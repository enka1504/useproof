Docs

Run Useproof locally, then build the proof layer.

The current CLI exposes the browser engine while the casefile runner, verdict engine, and dossier writer are built into the product surface.

Quickstart

terminal
cd /root/useproof
python3.11 -m venv .venv
source .venv/bin/activate
pip install -U pip
pip install -e ".[cli]"
useproof install
useproof doctor

Current CLI

Use these commands today to control the browser engine that the proof runner will wrap.

Open

useproof open https://example.com

Inspect

useproof state

Capture

useproof screenshot proof.png

browser session
useproof open https://example.com
useproof state
useproof screenshot proof.png
useproof close
