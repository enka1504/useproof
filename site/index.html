The wedge

Tests are brittle. Agents are opaque. Useproof makes runs inspectable.

Browser Use gives the automation engine. Useproof adds the product layer a team needs when a browser agent touches checkout, signup, admin, support, onboarding, or other critical flows.

Readable casefiles

Write natural-language objectives and explicit pass rules that fit in a pull request.

Durable run tapes

Keep the step-by-step record, page state, screenshots, browser trace, and model configuration.

Shareable verdicts

Produce JSON for CI and Markdown dossiers for humans who need to understand the result.

Workflow

From one YAML file to a proof dossier.

casefile.yml
case: checkout-smoke-test
objective: Prove checkout reaches an order confirmation.

agent:
  task: Log in, add the demo product to cart, and complete checkout.
  model: auto
  max_steps: 25

verdict:
  pass_when:
    - page_contains: Order confirmed
    - url_matches: /orders/
    - capture: confirmation_number

receipts:
  - screenshot
  - run_tape
  - dossier
case: login-regression
objective: Prove an existing user can sign in.

agent:
  task: Sign in with the test account and open the dashboard.
  model: auto

verdict:
  pass_when:
    - page_contains: Welcome back
    - url_matches: /dashboard

receipts:
  - screenshot
  - run_tape
  - browser_trace
case: admin-user-search
objective: Prove support can find a customer.

agent:
  task: Open admin, search for the demo customer, and view the profile.

verdict:
  pass_when:
    - page_contains: Customer profile
    - capture: account_status

receipts:
  - screenshot
  - dossier

Dossier output

A run should leave a compact evidence package with the casefile, browser state, final verdict, screenshots, extracted values, and a human-readable timeline.

  • CI exit codes for deploy gates
  • Markdown summary for PRs and incidents
  • JSON results for automation and dashboards
  • Receipts stored predictably in `.useproof/runs`
